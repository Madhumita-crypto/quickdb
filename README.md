# Quick Pharmacy Analytics

Interactive React/Vite dashboard prototype for the Quick Pharmacy analytics workspace.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The dashboard is intentionally built as a **workflow/UI prototype**. Values that are not part of the verified August workbook are explicitly treated as representative prototype values in the UI.

Primary workflow:

Overview → signal → dimension drilldown → Order Explorer → exact order/case context.
